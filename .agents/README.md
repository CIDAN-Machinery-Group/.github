This public repository owns CIDAN Machinery Group's GitHub organization profile.

- Edit [profile/README.md](../profile/README.md) for the public overview and support contact.
- Keep the CIDAN logo in [docs/assets/cidan-logo.png](../docs/assets/cidan-logo.png).

- [reference.md](reference.md) preserves the previous profile text for context.
